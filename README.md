# 💌 دعوت‌نامه تعاملی برای آیلین

یه پروژه کامل و آماده برای دعوت خاص از آیلین (آنیا / آنیشکا و ...).

طراحی شده با تم بنفش/صورتی رمانتیک، چندمرحله‌ای، و اتصال به تلگرام.

---

## ✨ امکانات

- سوال «با من میای سر قرار؟» با دکمه آره/نه (نه شوخی می‌کنه!)
- انتخاب اسم مورد علاقه (آیلین، آنیا، آنیشکا، خانم شاجری + ورودی دلخواه)
- انتخاب تاریخ و ساعت
- انتخاب مکان/فعالیت (کافه، رستوران، پارک، سینما، خانه+فیلم، سورپرایز)
- انتخاب غذا/نوشیدنی
- پیام اختیاری
- صفحه موفقیت با confetti
- ذخیره پاسخ‌ها در فایل JSON
- ارسال خودکار به تلگرام وقتی کسی پاسخ می‌ده

---

## 🚀 راه‌اندازی لوکال

```bash
# ۱. نصب پکیج‌ها
npm install

# ۲. کپی فایل env
cp .env.example .env

# ۳. توکن و آیدی تلگرام رو توی .env بذار (اختیاری برای تست)
# TELEGRAM_BOT_TOKEN=...
# TELEGRAM_CHAT_ID=...

# ۴. اجرا
npm start
```

بعد برو به: http://localhost:3000

## 📱 اتصال به تلگرام (خیلی مهم)

1. برو به تلگرام و به **@BotFather** پیام بده
2. دستور `/newbot` رو بزن و اسم و یوزرنیم ربات رو بساز
3. توکنی که می‌ده رو کپی کن → بذار توی `.env` به عنوان `TELEGRAM_BOT_TOKEN`
4. به ربات خودت یه پیام بفرست (مثلاً `/start`)
5. برو به **@userinfobot** یا **@getidsbot** و آیدی عددی خودت رو بگیر → بذار توی `.env` به عنوان `TELEGRAM_CHAT_ID`

حالا هر بار که آیلین پاسخ بده، مستقیم به تلگرام تو پیام می‌آد 💕

## 🌐 دیپلوی رایگان (Render.com – پیشنهاد من)

### روش ۱: Render (رایگان و پایدار)

1. برو به [render.com](https://render.com) و ثبت‌نام کن (با گیت‌هاب)
2. New → Web Service
3. ریپازیتوری گیت‌هاب پروژه‌ت رو وصل کن (یا فایل‌ها رو آپلود کن)
4. تنظیمات:
   - **Build Command:** `npm install`
   - **Start Command:** `npm start`
   - **Environment:** Node
5. توی بخش Environment Variables اینا رو اضافه کن:
   - `TELEGRAM_BOT_TOKEN` = توکن ربات
   - `TELEGRAM_CHAT_ID` = آیدی چت
6. Create Web Service بزن

بعد از چند دقیقه لینک عمومی می‌گیری (مثل `https://aylin-invite.onrender.com`)

> نکته: روی پلن رایگان Render بعد از مدتی inactivity می‌خوابه. اولین درخواست ممکنه ۱۵–۳۰ ثانیه طول بکشه.
